# Reference renders (the quality bar)

| File | What it is |
|---|---|
| `catru-contact-1.jpg`, `catru-contact-2.jpg` | LibreOffice render of the accepted 48-slide deck *Hành Trình Tái Sinh Nghệ Thuật Ca Trù Của Cậu Đàn Đáy* (NEKO CORE). Static keyframes: the Morph between them plays only in PowerPoint. `references/reference-bar.md` lists what was measured from it. |
| `styles-gallery.jpg` | The same five-slide starter deck (`studio.py new`) built with each style pack, top to bottom: lacquer-heritage, noir-product, paper-editorial, boardroom-data, studio-pop. |

`studio.py compare WORK RENDER_DIR` puts your contact sheet above `catru-contact-1.jpg` (or another sheet with `--ref`).
